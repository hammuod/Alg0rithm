Alg0rithm is a project to learn how to write, understand, and read algorithms for the normal developer, by Hammoud

Algorithm website

Algorithms are step-by-step instructions we use to solve problems or complete tasks. By learning algorithms, you start thinking in a clear, logical way before you write any code. Here we focus on how to write, read, and understand algorithms in a simple and practical style.
